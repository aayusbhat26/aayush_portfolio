# Certification learning plan

Updated 2026-11-05.

The public portfolio shows only the three completed credentials supplied with
proof: Oracle Cloud Infrastructure 2025 Foundations Associate, Udemy Complete
React Developer, and HackerRank REST API (Intermediate). This file is the
private learning plan for the 17 certifications displayed on the reference
portfolio (arhaanportfolio.in).

## Read this first: free to learn vs. free certificate

Most of these are Coursera courses. On Coursera:

- **Auditing is free.** You can watch the videos and read the material without
  paying, but you usually do not receive a certificate or graded assignments.
- **Financial aid can waive the certificate fee** for an individual course. It
  is an application, not a guarantee. Apply per course:
  https://www.coursera.support/s/article/209819033-Apply-for-Financial-Aid-or-a-Scholarship
- **A Coursera certificate is paid** if financial aid is not approved.

Genuinely free certificates or tests:

- HackerRank skill certification tests.
- Infosys Springboard courses and certificates.
- Google Skills course/badge completions (some labs require credits).
- Anthropic Academy course-completion certificates. The Claude Certified
  Architect exam itself is paid.

Paid credentials hidden behind course-completion labels:

- Google Cloud professional certifications.
- AWS certifications.
- Microsoft certifications.
- Anthropic Claude Certified Architect exam.

## Recommended sequence

Do not chase all 17 at once. For a backend/data profile, this order gives the
most signal per hour:

1. **HackerRank Software Engineer Intern** — free, fast, immediately verifiable.
2. **Infosys — Mastering Big Data Analytics with PySpark** — directly relevant
   and free.
3. **Meta — Introduction to Back-End Development** — backend refresh.
4. **IBM — Applied Software Engineering Fundamentals** — software foundations.
5. **IBM — DevOps and Software Engineering** — the largest commitment.
6. **Google Cloud Core Fundamentals** — cloud vocabulary.
7. **AWS — Generative AI with Large Language Models** — applied AI context.
8. **DeepLearning.AI — Neural Networks and Deep Learning** — ML foundations.
9. **IBM — Exploratory Data Analysis for Machine Learning** — data analysis.
10. **Anthropic Certified Claude Architect** — only after the free Academy
    courses; the exam is paid.
11. **Google — Introduction to Generative AI** — quick micro-course.
12. **Microsoft — Foundations of AI and Machine Learning** — quick overview.
13. **University of Michigan — Ethics in Engineering** — optional.
14. **Illinois — Leading Teams: Developing as a Leader** — optional.
15. **Google — Foundations of Project Management** — optional.
16. **Illinois — Digital Marketing Specialization** — optional, non-core.

## Notes

- The reference portfolio marks several of these as “in progress.” That is not
  a claim this portfolio makes. Only completed credentials appear publicly.
- Do not pay for every certificate. A public HackerRank test, an Infosys
  Springboard certificate, and one or two financial-aid Coursera completions
  are more useful than a long list of unpaid audits.
- The Claude Certified Architect exam is the most expensive item on this list.
  Finish the free Anthropic Academy material first and decide whether the
  credential is worth the fee for the roles you are targeting.
- For Coursera courses, apply for financial aid one course at a time. Approval
  usually takes several days; do not wait until a deadline.
